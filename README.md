
# Tic-Tac-Toe | VOSC Activity 1

## About the Project
A modern, interactive Tic-Tac-Toe game developed
using HTML, CSS, and JavaScript.

Play against a friend or challenge a computer
opponent with different difficulty levels.

## Features
- Player vs Player mode
- Player vs Computer mode
- Easy, Medium, and Unbeatable AI
- Minimax algorithm for the unbeatable AI
- Scoreboard for wins and draws
- Winning combination highlighting
- New Round and Reset Scores options
- Responsive user interface
- No external JavaScript libraries

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Choose a game mode and start playing.

## How to Play
1. Select Player vs Player or Player vs Computer.
2. In computer mode, choose a difficulty.
3. Player X always takes the first turn.
4. Take turns selecting empty cells.
5. Get three marks in a row, column, or diagonal
   to win.
6. If all cells are filled without a winner,
   the round ends in a draw.
7. Use New Round to play again.
8. Use Reset Scores to clear the scoreboard.

## AI Algorithm
The Unbeatable difficulty uses the Minimax
algorithm to evaluate possible moves and choose
the best available move.
