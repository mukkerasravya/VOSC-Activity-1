
# Tic-Tac-Toe Game | VOSC Activity 1

## About the Project
This is a simple, interactive Tic-Tac-Toe game
developed using HTML, CSS, and JavaScript.

The game is designed for two players who take
turns marking X and O on a 3x3 board.

## Features
- Two-player gameplay
- Automatic player turn switching
- Winner detection
- Draw detection
- Winning combination highlighting
- Restart game option
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in any modern web browser.
4. Start playing!

## How to Play
1. Player X starts the game.
2. Players take turns selecting empty cells.
3. The first player to get three marks in a
   row, column, or diagonal wins.
4. If all cells are filled without a winner,
   the game ends in a draw.
5. Click Restart Game to play again.
